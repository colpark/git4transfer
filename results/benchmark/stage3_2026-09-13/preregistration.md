# Stage 3 W1 floor pre-registration

Frozen 13 September 2026, before any W1 floor scores or measured DMS outcomes were inspected. Stage 1 sequence clusters and Stage 2 classical conventions are fixed inputs. The user's instruction to proceed is treated as opening **W1 Stage 3 only**; the PyRosetta-to-OpenMM W2 deviation is not accepted or used here. No arm runs are authorized by this file.

## Inputs and unit

Use ProteinGym PG_v1.3 substitution-assay CSVs, the matching reference metadata, released A2M MSAs, and released zero-shot score CSVs. Verify ZIP integrity and record SHA-256 hashes. A statistical unit is one **50%-identity sequence cluster** from Stage 1, never one mutant. Select one representative assay per cluster by the lexicographically smallest `DMS_id` among assays with target-sequence length 50–1,000 aa and a named MSA file. This cap is based on Stage 2b's 32K configured context and is imposed before outcomes are read. Report all excluded clusters; do not widen the cap to pass a band. Do not treat the 174-cluster supply as a completed cohort.

For each representative, parse only single-substitution `mutant` strings of the form `A123V`, require WT to match the reference sequence, no duplicate mutant, and require the position to map to an uppercase query column in the released A2M. The first A2M query's uppercase and lowercase residue sequence must equal the reference `target_seq[MSA_start-1:MSA_end]`; lowercase insertion positions have no PSSM column and are ineligible. Remove lowercase insertions and `.` from every A2M row; retain uppercase amino acids and `-` in aligned columns. Rows containing noncanonical aligned residues or unequal aligned length are excluded and counted, not converted to amino acids; require at least two valid rows with ≥80% full-query alignment coverage and at least two nongap residues at each scored column, matching Stage 2's convention. If an assay has fewer than 20 eligible single variants, mark it unavailable. From eligible variants, take the first **100** ordered by SHA-256 of `DMS_id + "|" + mutant` (all if fewer); this is label-blind and fixed before reading any `DMS_score`.

Where a raw file repeats the same mutant, use only its first occurrence for both candidate eligibility and its eventual measured label; do not average duplicate labels. The target is the ten highest-fitness variants in that supplied candidate set. ProteinGym defines larger `DMS_score` as greater experimental fitness. The candidate list and selection order must be saved without labels. Measured labels remain in a separate evaluation pass and are never passed to either floor's predictor.

## Floors, score direction, and missingness

**Floor C (classical):** at each candidate variant compute the Stage 2 Laplace-smoothed MSA PSSM mutant-minus-WT log-odds `delta_bits` with one pseudocount per amino acid and BLOSUM62 WT→mutant. Rank each measure within that item's candidate set, ascending with larger values better; use the average of the two normalized midrank percentiles as the combined score. Tie-break by the lexicographic mutant string. No score may be replaced by zero. Score the full released MSA; there is no two-copy toy or hidden reweighting.

**Floor M (mechanical):** a fixed, label-blind equal-rank ensemble of Floor C's combined score, the released `ESM2_650M` zero-shot score, and the released `ESM-IF1` score. Each present component is normalized to an ascending midrank percentile within the candidate set, then averaged. Every candidate in an item must have a finite ESM2 score, or the **whole item** is unavailable for Floor M and the paired floor comparison; missing ESM-IF1 is omitted per candidate and counted, never imputed as zero. Published model predictions were computed upstream; this stage makes **zero new foundation-model inference calls** and zero subject-LLM calls for either floor. This is not a claim that Floor M is model-free. The score archive also contains `DMS_score`; the predictor must explicitly allowlist only `mutant`, `ESM2_650M`, and `ESM-IF1` from it.

Top ten are the largest combined scores. Primary quantitative floor outputs are per-item Spearman rho of predicted scores against measured `DMS_score` and precision@10, the fraction of the predicted ten overlapping the measured ten best candidates. Higher is better. Macro-average across independent clusters, report per-floor coverage, and use 2,000 cluster bootstrap replicates with seed 19 to form 95% percentile intervals. Report paired Floor M minus Floor C only on items where both are evaluable. Do not tune weights, thresholds, or fallback based on these outcomes.

## Controls and contamination

For each floor, predictions must be byte-identical if measured labels are permuted; a scorer given sign-inverted measured labels must change the reported outcome. A missing/invalid MSA must make Floor C unavailable, not produce a numerical score. Missing ESM2 must make Floor M unavailable. Audit the predictions against the certified MCP primitive on a known short MSA; bulk floor calculation is a scripted implementation of that same published formula, **not** an MCP call per variant. The distinction must be disclosed in the finding.

For the eight-gram leakage audit, tokenize public prompt text and withheld title/assay metadata into lowercase alphanumeric words; report shared contiguous eight-word sequences. Also scan exact `DMS_id`, UniProt ID, source title, author, and PDB identifiers separately, because eight-word matching cannot detect single identifiers. A seeded copy of one prompt containing an eight-word title fragment and an exact ID must be caught; a clean control must not. An empty overlap is not proof of absence from pretraining data. Report publication-before-2025 exposure and a separate recitation burn rate.

The recitation probe is a **20-item**, SHA-256-selected subset of evaluable clusters, using the same source-free W1 prompt skeleton, one attempt each on the Stage 2b Qwen2.5 7B Q4 subject, no tools and no label access. Report an exact source-entry ID named *unprompted* as burn; no identification request or prompt coaxing. Record attempts separately from completed outputs, and call interrupted items UNDEMONSTRATED. Monitor the tested two-node thermal envelope with the same 90% GPU-utilization / 80°C GPU / 85°C CPU abort lines. This is a diagnostic, not Arm 1 scoring.

## Stage gate

Publish both floor tables, coverage and controls before any agent arm. Publish contamination and recitation reports even if burn is high; burn is not an Arm 1 exclusion gate. If true MSAs, score fields, or labels cannot be verified, mark the corresponding items unavailable and report the lower effective n. Do not widen any definition after seeing results. Stop after Stage 3 outputs for panel review; do not start Stage 4.
