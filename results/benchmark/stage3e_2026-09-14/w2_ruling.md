# Item 3 — W2 panel rulings accepted

**Recorded 14 September 2026, 02:51 UTC. No W2 assay scoring, arm run or model inference occurred in Stage 3e.** This implements the panel's 14 September ruling on [option A](../stage3d_2026-09-13/w2_ddg_ruling_request.md) and its additional priority ruling, not a new scientist-selected method.

1. **Rosetta-style W2 physics claim removed.** The OpenMM MCP endpoint is now named `openmm_snapshot_potential_delta`; the historical `openmm_delta_energy` name is not mounted. It compares one instantaneous, **unminimized** potential energy from each of two **user-supplied** prepared PDBs. It does **not** build a mutation, minimize either structure, sample conformations, calculate the unfolded state, or estimate folding ΔΔG. Its equal-atom-count guard rejects many side-chain-changing substitutions. It is a **structural diagnostic**, never a required W2 stability ranker. The earlier “minimized wild type versus minimized mutant” description was wrong; [the corrected card](../construct_validity_2026-09-14/tool_cards.md) and live MCP name now say what is actually computed. Historical Stage 2 receipts retain the old name as provenance, not current certification of the renamed endpoint.
2. `pyrosetta_ddg` stays **BLOCKED** for unverified institutional license and aarch64 build; it no longer points to OpenMM as a ddG substitute. Option B remains possible only if a licensed executable and mutation-specific protocol are later certified. The unmounted reference-energy algebra prototype from Stage 3e's predecessor has **no W2 scoring role** after this ruling.
3. **W2 demoted to secondary and deferred until W1 produces a result.** No W2 cohort, floor or arm runs now. The [MegaScale authors](https://www.nature.com/articles/s41586-023-06328-6) report limited success of physics-based stability simulation, and an [independent benchmark](https://doi.org/10.1371/journal.pcbi.1012248) found zero-shot ESM-2 less capable on MegaScale stability changes than on datasets whose readouts track function. A [later primary dataset analysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC13228446/) counts **199 clusters at 30% identity** in MegaScale, a stricter-dependence warning than our Stage 1 **238 usable clusters at 50%**. These are differently filtered denominators, so 199 is **not** asserted as the exact usable 30%-cluster count. Removing the energy tool weakens Arm 2 in the direction that could **inflate** an Arm 3–Arm 2 headline, and must be printed beside any later W2 comparison.

**Preregistered prediction, timestamp 2026-09-14 02:51 UTC, before any W2 run:** expect a **small or absent Arm 3 minus Arm 2 gap** on W2, with cluster-aware uncertainty. This is a directional prediction, not a post hoc threshold or observed result. The same prediction was already recorded in the pre-run [construct-validity note](../construct_validity_2026-09-14/w2_prediction_and_gate.md). A substantial reproducible gap would falsify it. Any eventual W2 methods and metrics still require a separate preregistration and panel opening; this ruling does not reopen Stage 4.
