# Stage 3e standing rules — amended 14 September 2026 UTC

The prior [working rules](../stage3b_2026-09-13/rules.md) remain in force. Stage 3e adds and applies the following:

1. **A gate must measure the quantity it claims to protect, from a specification.** A hardware-safety threshold must come from a published hardware specification or a readable hardware-authoritative passive, active or critical trip, with a stated margin. Do not round up the latest observation and call it a limit. If trip points are unreadable, report disposition (c) and do not substitute a guess. This is the third project correction of a gate/quantity mismatch.
2. **A tool must measure the quantity the task scores on.** Execution certification is not scientific construct validity. W2's OpenMM snapshot delta is a diagnostic, never a stability ranker; the physics claim is removed.
3. **Not checked is not pass.** Every check needs a must-fail control. An interrupted run is **UNDEMONSTRATED**, not a zero success rate or model failure.
4. **Do not widen a definition to make it pass.** Count scarce independent units, preserve the denominator and report the decision metric beside any ranking metric.
5. **Unknowns stay unknown.** No inferred GPU threshold is a CPU trip, no 20-candidate same-assay correlation is a 148-assay result, and no W2 score exists while W2 is deferred.
