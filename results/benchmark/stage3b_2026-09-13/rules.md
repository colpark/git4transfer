# 19C REE arm comparison — standing rules amendment

Source: the v0.1 `19C_REE_agentic_benchmark_spec.md` in `colpark/git4transfer`, the v0.2 Codex prompt pack supplied in the task, and this Stage 0b amendment. The separate `19C_Agentic_Workflow_Summary.pdf` named by v0.1 is not present in `git4transfer`, so this local file records the amendment without purporting to edit that absent PDF.

1. **A gate must count the scarce unit, not the abundant one.** The literal Stage 0b gate counts training-disjoint 50%-identity clusters containing a 50–600-aa chain and a positive-labeled chain, even if those are different chains. Report separately the stricter, operational count of clusters with a positive chain that itself passes the length cap; here those counts are 20 and 19, respectively.
2. Rules first; no model call until the classical frontier and residual are measured.
3. A candidate list is not a result. Price every gain against the floor/adjudicator that receives it.
4. Not checked is not pass. Every gate ships with a negative control.
5. A leak is any channel by which the question identifies the answer; numbers can identify more precisely than names.
6. Admission is truth-free. Confidence describes accuracy of the evidence pattern, not the item's outcome.
7. An instrument built on the candidate set cannot report the candidate set is wrong.
8. An engineer who repairs their own authorization has none.
9. **Report the decision metric, never the ranking metric alone.** Print the per-item chance baseline and lift where applicable. A high association or discrimination statistic does not establish that the thresholded or top-k decision is useful; the REE ROC-AUC/micro-F1, AF3-alone/total-score, and W1 Spearman/precision@10 pairs all showed this pattern. Added after the 13 September 2026 Stage 3 panel ruling; earlier results remain frozen.
10. **A tool must measure the quantity the task scores on.** Stage 2 execution certification (a–d) is insufficient for a scored run. Construct-validity criterion (e) requires a tool card stating its computed quantity, defining source, accuracy against the task's measured endpoint (or explicitly unknown), non-claims, and all number-changing conventions. A substitute is justified against that endpoint, not against the tool it replaces. Unknown accuracy is not a pass. Added 14 September 2026 UTC; earlier certification and floors remain historical results, not retroactively relabeled as construct-valid.

This is the working rules file for the local Stage 0b evidence. Panel approval and any change to the upstream project-rules source remain separate actions.
