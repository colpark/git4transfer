# W1/W2 classical scoring pre-registration

Frozen **2026-09-12 22:23 EST (2026-09-13 03:23 UTC)**, before any Stage 2 foundation-model installation or result. These settings are implementation requirements, not values tuned against W1/W2 labels.

| Quantity | Fixed convention | Validity control |
|---|---|---|
| PSSM | Input is an explicitly supplied, equal-length amino-acid MSA with query as first row; no sequence is added by the server. At each query position exclude gaps from depth `D`; require `D >= 2` and whole-query MSA coverage `>= 0.80`. Dirichlet/Laplace pseudocount **1 for each of 20 residues**: `p(a)=(n_a+1)/(D+20)`. Background `q(a)=1/20`. Score is `log2(p(a)/q(a))` in bits. No sequence reweighting; duplicates remain visible and count as input rows. Variant effect is mutant minus WT score at the same position. | Query outside the MSA, unknown residue, unequal row length, or insufficient depth fails. A two-row `AA/AA` MSA has positive A and negative C score. |
| Conservation | Per query position, empirical (no pseudocount) Shannon entropy over nongap residues; `C = 1 - H/log2(20)`. Require `D >= 2`; report observed `D`, gap fraction, and `C`. Rank sites by larger `C`; do not interpret conservation alone as effect direction. | A homogeneous column is 1.0, a balanced A/C column is `1-log2(2)/log2(20)`; empty column fails. |
| BLOSUM | **BLOSUM62**, raw integer substitution score from the canonical matrix, no rescaling. For a variant report matrix score for WT→mutant and zero effect for WT→WT. This is a prior, not measured DMS or ddG. | A→A = 4; A→R = -1; noncanonical residue fails. |
| Sequence identity | Global alignment of the two full input sequences. Exact matches divided by total alignment columns **including terminal and internal gap columns**; report both counts. Alignment uses BLOSUM62, affine gap open `-10`, extension `-0.5`, and one best alignment. This is **not** the Stage 1 CD-HIT clustering definition. | Identical sequences = 1; disjoint single residues = 0; empty input fails. |
| Search | MMseqs2 and BLASTP search only the explicit reference FASTA/database passed to the call; self hits are retained and annotated. Return identifier, bit score, E value, identity, alignment length and coverage where backend supplies them. No hidden remote corpus. | An exact sequence included in a tiny reference must be recovered; an absent database fails. |
| Motif | Literal regular-expression scan over the amino-acid sequence; overlapping hits retained, one-based closed coordinates. No claim that a motif establishes function. | `A..D` in `ACCD` hits positions 1–4; malformed expression fails. |
| Hydrogen-bond geometry | For explicit donor, hydrogen, acceptor 3D coordinates: D–A distance ≤3.5 Å, H–A ≤2.5 Å, D–H–A angle ≥120°. Coordinates are Å. A heavy-atom-only structure cannot be silently treated as a hydrogen-bond measurement. | Collinear D/H/A passes; acceptor 10 Å away fails. |
| Retrieval/ranking | Each W1/W2 candidate remains an explicitly supplied variant. Retrieve reference sequences from a declared database; calculate classical scores; compare candidates on the same scales; rank by a predeclared linear rule only after score availability; filter invalid/out-of-range mutations, then submit. Missing score stays missing, never zero. No item or cohort is selected here. | A variant whose WT disagrees with the supplied sequence fails before scoring. |

The analysis denominator is **174** W1 sequence clusters and **238** W2 clusters with a usable non-WT ddG row, as ruled by the panel. Raw W1 217 overstates 174 by **24.7%**. Arm 1 memory/recitation is measured as a burn column, never an exclusion gate. FMADV Test C is withdrawn; the readiness question is whether Arm 2 can make a genuine retrieve→score→compare→rank→filter→submit attempt, not whether every FM tool has a classical counterpart.
