# Stage 2 subject-model reachability and host safety

Recorded 12 September 2026, 23:20 EST. This is a plumbing test, **not** a W1 accuracy result. The W1 prompt and seven mounted MCP servers were fixed for both candidate families; no task-prompt coaxing or scoring was performed. The Qwen 7B fallback was used after the Qwen 30B run exceeded the requested GPU-use ceiling. Agent execution and all MCP servers were on `spark-112b` (`192.168.100.10`); the Qwen 7B model was served from `spark-0b70` (`192.168.100.11`). Thus both nodes were used.

The direct model-serving probes succeeded for Qwen 7B and GLM; the Qwen 30B service loaded and generated output, but its first Codex tool attempts were malformed. The `subject_model_call_success.csv` table has one row per model per server. All seven servers show **0 completed attempts and 0 successes** for each subject model, so a call success percentage is **undefined**, not 0%. No model has a valid submit receipt. These observations exclude all three from a scored arm **at this gate**; they do not establish that Qwen 7B or GLM intrinsically cannot use tools. The interrupted runs and the Qwen 7B provider-metadata error are explicit limitations, not silently converted to model failures.

The full subject traces are `subject_qwen_w1_trace.jsonl`, `subject_qwen7_w1_trace.jsonl`, and `subject_glm_w1_trace.jsonl`; the JSON summaries preserve model metadata, host placement, memory, stderr, and submissions. `subject_glm_w1_thermal_abort_trace.jsonl` preserves the earlier higher-thread GLM trial, also interrupted on temperature. No Stage 3 run may use these subject models as certified agents without a fresh, safe criterion-(c) demonstration and a panel ruling. A lower-power deployment or corrected model-provider integration is a new certification attempt, not an adjustment to these results.

For comparison, the separate reference-Codex smoke runs in `smoke_w1.json` and `smoke_w2.json` completed through every mounted server in unguided and guided modes. That proves the MCP plumbing, **not** the open-weight subject-model reachability.
