# Stage 2 finding — W1/W2 MCP certification (12 September 2026)

**Disposition for panel:** the local W1/W2 MCP plumbing is built and four non-scoring reference-Codex smoke passes succeeded, but this is **not** an arm or accuracy result. The required PyRosetta backend and original eight-tool scireason PubMed service are blocked; their substitutes are disclosed, not equated. **No open-weight subject model passed agent reachability:** Qwen 30B, Qwen 7B, and GLM each had zero completed MCP calls in safety-limited trials. Their per-server outcome and distinct failure modes are in `subject_model_call_success.csv` and `subject_model_report.md`. Stop here; no cohort, arm, scoring run, or task spec was made.

**Scarce units and corrections.** W1 is **174** 50%-identity DMS-assay clusters; W2 is **238** clusters with a usable non-WT stability row. W1 raw 217 overstates 174 by **24.7%**. FMADV Test C is withdrawn: lacking a classical counterpart is not a defect. Arm 1 memorization is a recitation-burn column, not a gate. The readiness test is Arm 2 *executability*, not counterpart coverage.

**Certification.** `certification.csv` has 20 tool/service rows: **16 CERTIFIED**, **2 SUBSTITUTED**, **2 BLOCKED**. Seven atomic classical tools and the guided composite passed known-value, negative-control, reference-Codex-agent reachability, and receipt-resolution checks. The same holds for ESM-2, ESMFold, ESM-IF1, DSSP, TM-align, sequence identity, and both record tools. OpenMM potential-energy difference and one NCBI PubMed search tool passed all four tests but are marked **SUBSTITUTED** for PyRosetta and scireason respectively. PyRosetta has no verified licensed executable aarch64 build here; the original scireason server and its eight unnamed tools could not be contacted. Individual test records and Codex JSONL traces accompany the table. The classical score settings in `conventions.md` were frozen before any FM backend was installed.

**Full plumbing.** One ProteinGym W1 item and one MegaScale W2 item were run end-to-end in both unguided and guided presentation modes with all seven servers mounted. Each of the **four** runs called every server successfully, made one submission, and cited real receipt IDs. The guided composite was used in both guided runs. The audit deliberately tampered with a call ID and rejected it. These are smoke runs only: the W1 MSA was a two-copy toy, the W2 assay construct is **72 aa** whereas the independent 1UBQ structure control is **76 aa**, and no assay label was read. An initial W2 trace with a wrong “74 aa” prose label is retained as superseded; the corrected trace is authoritative.

**Arm 2 executability.** With classical MCP plus the universal record server, both W1 and W2 can retrieve from an explicit FASTA, score a valid substitution (PSSM/conservation/BLOSUM/motif or explicit H-bond geometry), compare score vectors and sequences, rank/filter via the agent, and submit. This is a genuine attempt, not a validated predictor; classical scores are not experimental ΔΔG. No stage lacks a classical path. A numerical cross-score aggregation rule was **not** pre-registered and may not be invented from these smokes; the panel must freeze one before any scored arm.

**Two-node subject trial and stop.** The MCP servers run on `spark-112b` (`192.168.100.10`, Linux aarch64); Qwen 7B was served from `spark-0b70` (`192.168.100.11`) while the agent and its MCP servers remained on node 10. The Qwen 30B GPU trial reached approximately 92–93% utilization despite the ceiling and was stopped; CPU-only Qwen 7B and GLM trials were stopped at 86.6°C and 87.3°C thermal readings respectively. No model is selected by quality or reachability. Current ESMFold ran on GB10 in the earlier plumbing smoke; OpenMM ran locally. CMU deployment and BNL HTTP hosting remain unverified; no server is proven BNL-only. `blocked.md` details the license, architecture, confidence-score, and substitution limits. The panel must rule on those deviations and the subject-model gate before Stage 3. Do **not** build a cohort or start arms.
