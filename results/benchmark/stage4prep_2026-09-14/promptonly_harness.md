# Prompt-only B1/B2 harness and parser, pre-scoring specification

14 September 2026. Implementation: [`stage4prep_promptonly.py`](../../../benchmark-mcp/stage4prep_promptonly.py); synthetic controls: [`stage4prep_parser_controls.py`](../../../benchmark-mcp/stage4prep_parser_controls.py). Both are hashed in `freeze_hashes.json` before any sealed-item smoke. The only model-visible input is the frozen Stage 3 W1 source stem, protein sequence and supplied candidate list, followed by a plain-JSON version of the same ten-pick decision contract. B1a/B2a insert one additional exact sentence, “Do not use foundation models.” B1b/B2b omit it. Source assay/PDB identifiers and labels are not in the prompt. Homolog/PDB paths and record-channel instructions are omitted because no tool exists to read or submit through them. A single model response must contain the answer; no tool loop, retry, reprompt, or answer repair is permitted.

The parser accepts **one plain JSON object** with exactly `item_id`, `selected`, `rejected`, and `ranking`. `item_id` is `pilot_item`. `selected` has ten unique supplied mutants with ranks 1–10 in array order, nonempty `basis` and `would_overturn`, and empty `evidence`/`validation` arrays; no receipt can exist in a prompt-only condition. `rejected` contains each nonselected candidate exactly once with a nonempty reason. `ranking` contains every supplied candidate exactly once with finite numeric scores sorted descending, lexical mutant tie-break, and its first ten mutants exactly match selected order. The item can have fewer than 100 candidates; the full ranking then means all its supplied candidates. No fence, prefatory text, partial JSON, omitted fields, fabricated receipt, or inferred missing value is accepted. A parser failure is **unavailable/invalid with coverage reported**, never silently scored as zero.

Controls written to `parser_controls.json` before any model smoke: a valid synthetic 100-candidate answer passes; malformed JSON, nine picks, eleven picks, duplicate pick, invented receipt, and incomplete ranking each fail. A parser that cannot reject these controls is not frozen. These controls use synthetic variants only and open no benchmark labels.

Serving guard: the B2 Qwen path sends an OpenAI-style chat request directly to llama.cpp with no `tools` field and must capture the raw request as proof. The signed-in Codex path used for B4 retains native tool declarations even with MCP unmounted; it is **not** automatically a compliant B1 path. A B1 smoke may run only after the forwarded frontier request is verified to have no tool definitions. “No tool was called” does not satisfy “no tool was visible.”
