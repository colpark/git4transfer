# Stage 2 benchmark MCP

W1/W2-only servers. Start a STDIO server with
`benchmark-mcp/.venv/bin/python benchmark-mcp/server.py --server classical --presentation unguided`.
The same entry point accepts `analysis`, `physics`, `predictive`, `generative`,
`lit`, and `record`; a name being mounted never implies scientific certification.
All responses carry a receipt and are stored under
`results/benchmark/stage2_2026-09-12/artifacts/`.

`conventions.md` was frozen before the first model backend was installed.
`certification.csv` is the historical Stage 2 execution disposition. `lit` is a
disclosed NCBI E-utilities substitute for unavailable scireason-mcp; physics
exposes blocked PyRosetta and `openmm_snapshot_potential_delta` as a structural
diagnostic only. The former `openmm_delta_energy` name is not mounted; no
OpenMM ddG or required W2 stability ranker is authorized after the Stage 3e ruling.
`screen_variant_classical` exists only in guided mode. The two smoke JSON files
contain all four full non-scoring Codex MCP traces, one W1 and one W2 item in
each presentation mode.
